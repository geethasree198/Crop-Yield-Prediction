# 🌾 Crop Yield Prediction

A machine learning-based system for predicting crop yield using environmental conditions, soil characteristics, and crop-specific parameters.

## 📌 Project Overview

Crop Yield Prediction is a machine learning project designed to estimate crop yield based on multiple agricultural parameters.

The system considers environmental factors such as temperature, humidity, and wind speed, along with soil characteristics including nitrogen, phosphorus, potassium, pH, and soil quality.

The project focuses on predicting the yield of major crops including wheat, corn, rice, barley, and soybean.

## 🎯 Objectives

- Develop a machine learning-based crop yield prediction system.
- Analyze multiple environmental and soil parameters.
- Implement Random Forest Regression for yield prediction.
- Incorporate additional machine learning techniques for improved prediction.
- Develop an interactive dashboard for users.
- Explore cloud-based deployment for scalable access.

## 📈 Results

The project reports an R² value of 97.5% and an RMSE of 4.1 for the developed prediction system.

The application provides crop yield predictions and visual analysis based on the selected agricultural parameters.
